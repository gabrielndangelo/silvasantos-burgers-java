# SilvaSanto's Burgers

Primeiro microprojeto desenvolvido em Java durante meus estudos de programação antes de Programação Orientada a Objetos.

O projeto simula o atendimento de uma lanchonete fictícia, permitindo ao usuário consultar um cardápio, realizar pedidos e escolher uma forma de pagamento.

## Objetivo

Praticar os fundamentos de Java através da construção de um pequeno sistema baseado em uma situação do mundo real (de microempresa.)

## Funcionalidades

- Cadastro simulado de cliente
- Exibição de cardápio
- Escolha de produtos
- Escolha de acompanhamentos, bebidas e sobremesas
- Possibilidade de adicionar mais de um item ao pedido
- Cálculo do valor total
- Pagamento com cartão, Pix ou dinheiro
- Simulação e bloqueio de senha do cartão
- Cálculo de troco

## Conceitos praticados

- Variáveis e tipos de dados
- `Scanner`
- `if/else`
- `switch/case`
- `while`
- `do/while`
- `String`
- `char`
- Operações matemáticas
- Entrada e saída de dados

## Tecnologias

- Java
- Eclipse IDE
